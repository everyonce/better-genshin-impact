BetterGI local setup -- 2026-10-22

Launch Start-BetterGI.cmd from the repository root, or run:
  artifacts\BetterGI-English-win-x64\BetterGI.exe
Keep the whole portable directory together. It includes the .NET runtime,
recognition models, map assets, and the rebuilt English embedded web interfaces.
The initial interface and game language settings are English.

The integration includes Pulonia plans, resource repositories and versioned
snapshots, unified standalone tasks, account preparation, inference engine
management, local external access, and desktop-session diagnostics. Fork quest
helpers now use explicit runtime instances and per-run cancellation tokens.

Rebuild in PowerShell 7 with Git, Node.js/npm and the .NET 10 SDK:
  .\Build\Scripts\build-local.ps1
This machine's downloaded toolchain and package caches are inside the workspace.
To compile without publishing or launching BetterGI, use:
  .\Build\Scripts\build-local.ps1 -VerifyOnly
This also selects the workspace .NET 10 SDK and existing NuGet package cache.
Existing portable directories are never overwritten. For another build, choose
an empty output directory explicitly:
  .\Build\Scripts\build-local.ps1 -OutputDirectory .\artifacts\release-r57\BetterGI-English-win-x64
Use -RebuildWeb to rebuild both pinned embedded web interfaces too.
Choose a new, unused release number for each build. Numbered publishes and staged
runtimes automatically retain R1, R55, R56 and the two newest successful builds.
In-use and incomplete builds are preserved. Superseded program files are removed;
settings, recordings, test results and other retained data move to
artifacts\release-evidence\release-rN. Each archive's release-retirement.json maps
original paths to archive paths. Build\release-retention.json controls the policy.
Preview cleanup with .\Build\Scripts\manage-release-retention.ps1 -Action Plan.
