# Persistent field progress guard

`field-progress.js` keeps the most recent16 movement attempts in runtime `field-progress-history.json`. The adapter checks it before closing Inventory and writes the pending attempt before any game input. An uncertain terminal remains protective. Camera-only inspection does not erase movement history. Existing identity, focus, freshness, health, stamina and action bounds still apply.

Near a recent climb, horizontal coordinates are not vertical progress evidence. A repeat requires either a decreased `Higher Nm` reading for the same nonempty objective, or a review tied to the exact previous start/current witness frames. A vertical landmark review records the named fixed feature and measured downward screen displacement with unchanged camera. A different-approach review requires a materially changed heading and an explicitly visible traversable exit. Camera rotation, action-duration changes, lateral pulses and a full-health fall alone do not establish progress. The review is manual evidence, not automatic image recognition.

The planner exposes `--progress-review` JSON and applies the same guard before writing a request. Runtime enforcement remains independent of that planner. Missing or corrupt history fails closed for movement; install with an explicit empty version1 history for a genuinely new runtime, or reconstruct the recent attempts from its receipts. Never clear history to retry a rejected action. Installation for this mission seeds the recorded1066→1074 failed corner; its fall/landing1084 remains an intervention with zero damage.

Recorded regression frames1058,1066,1074,1084 and1113 are retained as compact JSON with original screenshot hashes. Tests distinguish vertical evidence from coordinate drift and reject uncertain or same-state repeats. The successful dry-shelf return1113 is a separate observed traversal; it does not make the fallen corner a reliable exit. This guard covers field-plan batches; native navigation retains its existing coordinate stall/recovery guards.
